# FinTrack Development Log

## Обзор проекта
FinTrack — это MVP финтех-агрегатора для управления финансами на российском рынке. Приложение портируется на платформу Replit с использованием PostgreSQL базы данных.

## Архитектура
- **Frontend**: React + TypeScript + Tailwind CSS + shadcn/ui
- **Backend**: Express.js + Node.js
- **База данных**: PostgreSQL на Replit
- **ORM**: Drizzle ORM
- **Аутентификация**: JWT + bcrypt
- **Шифрование**: AES-256-GCM для финансовых данных
- **AI**: OpenAI API для финансового ассистента
