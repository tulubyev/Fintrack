# FinTrack API Routers Documentation

Документация по модульным роутерам backend API FinTrack.

## Обзор архитектуры

FinTrack использует модульную архитектуру роутеров для лучшей организации кода и разделения ответственности. Каждый роутер отвечает за определенную область функциональности.

## Основные модули

### 🔐 [Auth Router](./auth.md) (`/api/auth/*`)
**Аутентификация и авторизация**
- Регистрация и вход пользователей
- JWT токены (access/refresh)
- Двухфакторная аутентификация (2FA)
- Интеграция с Госуслугами

### 👨‍💼 [Admin Router](./admin.md) (`/api/admin/*`)
**Административное управление**
- Многоуровневая система ролей (6 типов админов)
- Управление пользователями и документами
- Аудит и логирование действий
- Системная аналитика

### 📄 [Documents Router](./documents.md) (`/api/documents/*`)
**Управление документами**
- End-to-End шифрование файлов (AES-256)
- Загрузка и верификация документов
- Безопасный просмотр и скачивание
- Поддержка различных типов документов

### ✅ [Verification Router](./verification.md) (`/api/verification/*`)
**Верификация пользователей**
- SMS верификация через SMS.RU
- Email верификация через SMTP
- Тестирование сервисов связи
- Защита от злоупотреблений

### 🏦 [Banks Router](./banks.md) (`/api/banks/*`)
**Банковские операции и платежи**
- Подключение к банкам через ПКС (Open Banking)
- Российские платежные системы (ЮKassa, CloudPayments)
- Управление счетами и транзакциями
- OAuth2 интеграция с банками

### 📊 [Dashboard Router](./dashboard.md) (`/api/dashboard/*`)
**Аналитика и статистика**
- Сводная финансовая статистика
- Анализ трат по категориям
- Данные для построения графиков
- Административная аналитика

## Архитектурные принципы

### Модульность
- Каждый роутер изолирован в отдельном файле
- Четкое разделение ответственности
- Легкость тестирования и поддержки

### Безопасность
- Все роуты требуют аутентификации
- Ролевая модель доступа
- Валидация данных через Zod схемы
- Rate limiting для критичных операций

### Российская специфика
- Соответствие требованиям ЦБ РФ
- Интеграция с ЕСИА (Госуслуги)
- Поддержка российских платежных систем
- Соблюдение 152-ФЗ о персональных данных

## Структура файлов

```
server/routes/
├── index.ts           # Главный роутер, объединяющий модули
├── auth.ts           # Аутентификация и авторизация
├── admin.ts          # Административное управление
├── documents.ts      # Управление документами
├── verification.ts   # SMS/Email верификация
├── banks.ts          # Банки, платежи, счета
└── dashboard.ts      # Аналитика и статистика
```

## Middleware

### Аутентификация
- `authenticateToken` - проверка JWT токена
- Автоматическое обновление токенов
- Детализированная обработка ошибок

### Авторизация  
- `requireAdmin` - проверка административных прав
- Ролевая модель с гранулярными разрешениями
- Логирование всех административных действий

### Безопасность
- Rate limiting по IP и пользователю
- Валидация входных данных
- CORS настройки для production
