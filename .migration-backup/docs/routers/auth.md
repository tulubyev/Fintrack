# Auth Router (`/api/auth/*`)

Модуль аутентификации и авторизации пользователей FinTrack.

## Основные функции
- Регистрация и вход пользователей
- Управление JWT токенами (access/refresh)
- Двухфакторная аутентификация (2FA)
- Интеграция с Госуслугами (mock)

## Роуты

### POST `/api/auth/register`
**Регистрация нового пользователя**
- Проверка уникальности телефона/email
- Хеширование пароля (bcrypt)
- Создание пользователя в БД
- Возврат токенов авторизации

### POST `/api/auth/login`
**Авторизация пользователя**
- Проверка учетных данных
- Генерация access/refresh токенов
- Установка secure cookies для refresh токена
- Возврат данных пользователя + токенов

### POST `/api/auth/refresh`
**Обновление access токена**
- Валидация refresh токена из cookies
- Генерация нового access токена
- Обновление refresh токена

### POST `/api/auth/logout`
**Выход из системы**
- Очистка refresh токена из cookies
- Завершение сессии

### GET `/api/auth/verify`
**Проверка статуса авторизации**
- Валидация access токена
- Возврат данных текущего пользователя
- Проверка прав и статуса верификации

### POST `/api/auth/gosuslugi`
**Mock авторизация через Госуслуги**
- Имитация OAuth2 интеграции с ЕСИА
- Создание/обновление пользователя
- Автоматическая верификация через гос. данные

## Двухфакторная аутентификация

### POST `/api/auth/2fa/setup`
**Настройка 2FA**
- Генерация TOTP секрета
- QR-код для подключения приложения
- Создание backup кодов

### POST `/api/auth/2fa/verify`
**Верификация 2FA кода**
- Проверка TOTP кода
- Активация двухфакторной аутентификации

### POST `/api/auth/2fa/disable`
**Отключение 2FA**
- Валидация текущего пароля
- Деактивация двухфакторной аутентификации

### POST `/api/auth/2fa/backup-verify`
**Использование backup кода**
- Верификация резервного кода
- Одноразовое использование кода

## Безопасность
- Все пароли хешируются с использованием bcrypt
- JWT токены с коротким временем жизни (15 мин access, 7 дней refresh)
- Secure HTTP-only cookies для refresh токенов
- Rate limiting на критичные эндпоинты
- Валидация данных с помощью Zod схем

## Используемые сервисы
- `authService` - основная логика аутентификации
- `twoFactorService` - управление 2FA
- `storage` - работа с базой данных пользователей
