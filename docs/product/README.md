# Продукт FinTrack: план развития

Цель — массовое приложение личных финансов для России (веб, Android, iOS): нейтральный финансовый
помощник поверх всех банков. Стратегия и анализ рынка (октябрь 2026) сведены в `ROADMAP.md`.
