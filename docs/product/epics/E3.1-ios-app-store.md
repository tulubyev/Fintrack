# E3.1 — iOS-приложение и публикация в App Store

**Оценка:** 12 дней (без ожидания ревью) · **Зависит от:** E2.1 (общий код Expo), E2.2 (APNs — только T4), D17 (решено: TestFlight сразу), аккаунт Apple Developer · **Блокирует:** —

> **Решение D17 (24.10.2026):** iOS идёт вместе с Android, не на этапе 3. Сначала — ранний трек TestFlight (T1–T3 ниже, параллельно с E2.1), публикация в App Store — после беты. Разработка в Expo Go на iPhone, нативное (SQLCipher, «Поделиться») — в сборке TestFlight.

## Цель
Дать пользователям iPhone нативное приложение, которое уже есть на Android. Оно бесплатное и без платёжных функций. При удалении из App Store остаётся PWA (E1.7) как полноценная замена.

## Пользовательские истории
- Как пользователь iPhone, я хочу установить FinTrack из App Store и войти по Face ID.
- Как пользователь iPhone, я хочу поделиться PDF-выпиской из «Файлов» или почты в FinTrack.
- Как пользователь с подпиской, оплаченной на сайте, я хочу получить платные функции в iOS после входа.

## Ключевые решения
- **Тот же код Expo**, вариант `ios`:
  - без чтения уведомлений (на iOS невозможно);
  - без экрана оплаты и без ссылок на внешнюю оплату (anti-steering; **проверить** актуальные правила App Store Review Guidelines 3.1.x для российского аккаунта);
  - права подписки подтягиваются из API.
- **Аккаунт разработчика Apple** ($99/год): оплата и регистрация из РФ затруднены (**проверить** варианты — организация с D-U-N-S, иностранное юрлицо-партнёр). Это главный блокер (D17).
- **Ревью:**
  - в описании, скриншотах и тестовых данных — без названий подсанкционных банков (Сбер, ВТБ, Альфа и т. д.), банки упоминаются обобщённо («импорт выписок российских банков»);
  - тестовый аккаунт для ревьюера с синтетическими данными;
  - экспортное соответствие (шифрование — стандартное, `ITSAppUsesNonExemptEncryption = false`, **проверить**).
- **Импорт:** Share Extension через config-plugin (`expo-share-intent` или аналог — **проверить** поддержку iOS-расширения в выбранном SDK), выбор файла через `expo-document-picker`.
- **Push:** APNs ключ `.p8`, прямые HTTP/2 запросы с сервера (E2.2).
- **Хранение:** Keychain с `kSecAttrAccessibleWhenUnlockedThisDeviceOnly`; Face ID с `NSFaceIDUsageDescription`.
- **Запасной путь при удалении:** в приложении есть экран «Если приложение пропадёт из App Store — откройте fin-wall.ru и добавьте на экран „Домой“». E-mail-рассылка пользователям iOS при удалении.
- **Исследование:** автоматизация «Быстрые команды» (iOS 17+) «при получении SMS от банка» → запуск команды с POST на `/v1/transactions/ingest` с персональным токеном. Это частичная замена E2.3 для SMS. Сделать как опцию для продвинутых пользователей, если подтвердится техническая возможность (**проверить**).

## Модель данных и API
Новых таблиц нет. Персональные токены для «Быстрых команд» (если делаем): `api_tokens(id, userId, name, hash, scopes: ['transactions:ingest'], lastUsedAt, revokedAt)`, `POST/GET/DELETE /v1/api-tokens`.

## Экраны
Как на Android. Без paywall: на месте платных функций — «Доступно в FinTrack Плюс» без кнопки оплаты (**проверить** допустимость формулировки).

## Метрика
Приложение прошло ревью. Доля iOS среди активных ≥ 25% через 3 месяца. Crash-free ≥ 99,5%.
