# E2.4 — AI-советник на данных пользователя

**Оценка:** 18 дней · **Зависит от:** E1.* (данные), E1.6 (подписки), D2 (провайдер и 152-ФЗ); E2.5 и E2.6 — дополнительные инструменты · **Блокирует:** платный тариф (основная платная функция)

## Цель
Ассистент отвечает на вопросы о деньгах пользователя цифрами из его же данных:
- «сколько я трачу на такси»;
- «почему в октябре ушло больше»;
- «где сэкономить 5 000 ₽ в месяц»;
- «успеваю ли накопить на отпуск».

Каждое число в ответе получено инструментом (SQL на сервере), а не придумано моделью, и сопровождается ссылкой на операции. Так закрывается разочарование 46% людей, которых не устроили советы нейросетей.

## Что есть в коде сейчас
- `services/aiService.ts`: OpenRouter → `anthropic/claude-3.5-sonnet` (модель устарела), контекст `monthlyIncome: "0"`, `topCategories: []`. Мок-ответы с выдуманными цифрами («45,230 ₽ на продукты», «ИИС в Тинькофф под 18%»).
- `routes/ai.ts` `POST /ai/chat`:
  - системный промпт разрешает «ответы на любые познавательные вопросы»;
  - принимает от клиента `context` с ролями;
  - напрямую вызывает OpenRouter `fetch`.
- `GET /ai/balance` раскрывает баланс ключа любому пользователю.
- Хранение: `ai_chat_sessions.messages jsonb` — вся переписка в одном поле.
- UI: `components/ai-chat.tsx`, `modals/AIChatModal.tsx`, `dashboard/AIAssistant.tsx`.

## Пользовательские истории
- Как пользователь, я хочу спросить «сколько я потратил на кафе за 3 месяца» и получить сумму, разбивку и ссылку на операции.
- Как пользователь, я хочу спросить «где сэкономить 5 000 ₽» и получить 3–5 конкретных пунктов с суммами (подписки-дубли, рост категории, переплата за кешбэк).
- Как пользователь, я хочу, чтобы советник не рекламировал конкретные банки и не выдумывал ставки.
- Как пользователь, я хочу понимать, куда уходят мои данные и как это отключить.

## Ключевые решения
- **Архитектура:** серверный агентный цикл (не больше 6 шагов). Модель с function calling получает список инструментов и вызывает их, сервер исполняет. В модель уходят только результаты инструментов — агрегаты и короткие списки, без номеров счетов и карт, без ФИО из P2P (имена заменяются на «Получатель 1»).
- **Инструменты** (все с обязательным серверным `userId`, модель его не передаёт):

| Инструмент | Параметры | Возвращает |
|---|---|---|
| `get_spending_summary` | `from`, `to`, `groupBy` (`category`, `merchant`, `month`), `categoryCodes?` | агрегаты с суммами и долями, `ref` на фильтр |
| `list_transactions` | фильтры E1.1, `limit ≤ 30` | дата, сумма, категория, мерчант, `id` |
| `compare_periods` | `periodA`, `periodB`, `groupBy` | дельты по категориям |
| `get_budgets_status` | `month` | статусы бюджетов |
| `get_goals` | — | цели с прогнозом |
| `get_recurring` | `kind?` | серии с суммами в месяц и год, пересечения |
| `find_savings_opportunities` | `targetMonthly?` | заранее посчитанные эвристики: дубли подписок, рост категорий выше медианы за 6 мес. на 30%+, комиссии банков, недополученный кешбэк (E2.5), проценты по кредиткам |
| `get_cashback_advice` (E2.5) | `merchant?`, `categoryCode?` | карта и ставка |
| `get_tax_deductions` (E2.6) | `year` | оценка вычетов |

- **Ссылки:** результат инструмента содержит `refs: [{ type: 'transactions', filter: {...} }, { type: 'recurring', id }]`. Ответ модели размечает их (`[[ref:1]]`), UI превращает их в кнопки «Показать 14 операций».
- **Проверка чисел:** пост-валидатор извлекает из ответа все суммы и проценты и сверяет с числами из результатов инструментов (с допуском округления). Если число не найдено — один повтор с инструкцией «используй только числа из инструментов», при повторной ошибке число удаляется и добавляется пометка.
- **Рамки:**
  - только личные финансы пользователя и общая финграмотность;
  - вопросы не по теме — вежливый отказ;
  - без рекомендаций конкретных ценных бумаг;
  - без названий банков в советах о продуктах (это зона E3.4 с маркировкой «Реклама»);
  - дисклеймер «не является индивидуальной инвестиционной рекомендацией» — там, где речь об инвестициях.
- **Провайдер (D2, решено 18.10.2026):** RouterAI (routerai.ru) — один OpenAI-совместимый клиент `LlmProvider` с function calling:
  - адрес, ключ и модели — в `.env` (`LLM_BASE_URL`, `LLM_API_KEY`, `LLM_ADVISOR_MODEL`, `LLM_CATEGORIZATION_MODEL`);
  - модель советника — по eval-набору (T7) среди доступных через RouterAI: российские (GigaChat, YandexGPT — **проверить** наличие) и зарубежные;
  - в модель уходят только обезличенные агрегаты и операции; зарубежная модель — только после проверки 152-ФЗ (D2, «Ещё открыто»).
- **Хранение:** переписка в новых таблицах, срок 90 дней (настраивается), удаление по кнопке. `ai_chat_sessions` мигрировать и удалить.
- **Лимиты по тарифу (D7):** Free — 10 вопросов в месяц, Плюс — 300. Учёт токенов и стоимости в рублях на запрос.
- **Удаляется:** `POST /ai/chat` с произвольным контекстом, `GET /ai/balance` (перенести в админку), мок-ответы.

## Модель данных крупно
```ts
aiConversations(id, userId, title, createdAt, updatedAt, deletedAt)
aiMessages(id, conversationId, userId, role: user|assistant|tool, content text, toolCalls jsonb, toolName, refs jsonb,
           provider, model, tokensIn, tokensOut, costKopecks, latencyMs, validation: ok|retried|stripped, createdAt)
aiUsage(userId, month date, questions int, tokens int, costKopecks int)  // PK (userId, month)
aiFeedback(messageId, userId, rating: up|down, reason, createdAt)
```

## API крупно
- `POST /v1/ai/conversations` → `{ id }`.
- `GET /v1/ai/conversations`, `GET /v1/ai/conversations/{id}/messages`.
- `POST /v1/ai/conversations/{id}/messages` `{ text }`.
  - Ответ — потоковый, SSE: события `tool_started{name}`, `delta{text}`, `refs`, `done{messageId}`.
  - Ошибки: `403 PLAN_LIMIT_REACHED`, `503 AI_UNAVAILABLE`, `400` (> 1 000 символов).
- `DELETE /v1/ai/conversations/{id}`.
- `POST /v1/ai/messages/{id}/feedback`.
- `GET /v1/ai/insights` — 3 заранее посчитанные карточки для главной, без LLM. Строятся из `find_savings_opportunities`; LLM только перефразирует (опционально).

## Экраны
- **«Советник»:** чат, подсказки-вопросы при пустом диалоге («Куда ушли деньги в октябре?», «Где сэкономить 5 000 ₽?», «Успею накопить на отпуск?»), индикатор «Считаю траты по категориям…» во время вызова инструментов, кнопки-ссылки на операции, 👍/👎, счётчик оставшихся вопросов для Free.
- **Карточка на главной:** 1–3 инсайта с цифрами.
- **Настройки → «AI и данные»:** провайдер, что передаётся, согласие (если нужно), «Удалить историю».

## Метрика
Eval-набор из ≥ 60 вопросов на 3 синтетических профилях с эталонными ответами из SQL: ≥ 95% чисел совпадают, ≥ 90% ответов по теме. В проде: доля 👍 ≥ 70%; ≥ 25% MAU задают вопрос в месяц; советник — главная причина апгрейда (опрос при оплате).

## Риски и вопросы
- **152-ФЗ** — D2 блокирует запуск. Без решения доступен только режим `GET /v1/ai/insights` без LLM.
- **Стоимость.** Ориентир — не больше 1,5 ₽ за вопрос при средних 3 вызовах инструментов (**проверить** тарифы провайдеров); лимиты по тарифу.
- **Prompt injection через данные** (описание операции «игнорируй инструкции…»): описания попадают в модель только как значения в JSON результата инструмента, плюс системная инструкция. Инструменты только читают, писать модель не может ничего.
