# E3.2 — Семейный бюджет

**Оценка:** 18 дней · **Зависит от:** E1.4 (бюджеты и цели), E2.8 (тариф «Семья»), E2.2 (уведомления участникам) · **Блокирует:** —

## Цель
Семья ведёт общий бюджет поверх разных банков. Каждый сам решает, какие счета показывать: полностью, только остаток или никак. Общие бюджеты и цели считаются по операциям всех участников. Ни один банк этого не делает: его семейные функции работают только внутри банка.

## Что есть в коде сейчас
- `family_groups(name, admin_user_id, invite_code varchar(10) unique)`.
- `family_group_members(group_id, user_id, role: admin|member|observer, permissions jsonb)`.
- `users.role` со значениями `family_admin` / `family_member`.
- `UserStorage`: `getFamilyGroupsByAdmin`, `createFamilyGroup`, `addFamilyGroupMember`.
- Маршрутов и экранов нет.

## Пользовательские истории
- Как глава семьи, я хочу пригласить супругу по ссылке и вести общий бюджет на продукты, куда идут траты с моих и её карт.
- Как участник, я хочу показать семье остаток накопительного счёта, но не операции по личной карте.
- Как родитель, я хочу добавить подростка наблюдателем с доступом только к его карте и копилке.
- Как участник, я хочу общую цель «Отпуск», куда каждый вносит свою часть, и видеть вклад каждого.
- Как участник, я хочу выйти из группы, и мои данные перестанут быть видны.

## Ключевые решения
- **Группа:** до 6 участников. Роли:
  - `owner` — платит тариф «Семья» и управляет группой;
  - `adult` — видит общее, создаёт общие бюджеты и цели;
  - `teen` — видит только то, чем с ним поделились.
- Приглашение — ссылка с одноразовым токеном на 7 дней (существующий `invite_code` заменить на таблицу приглашений). Участник может состоять только в одной группе.
- **Видимость — на уровне счёта:** `account_shares(accountId, groupId, visibility: hidden | balance | full)`, по умолчанию `hidden`.
  - `full` — участники видят операции этого счёта, без заметок, с пометкой автора;
  - `balance` — только остаток.
- **Общие бюджеты:** `budgets.group_id` (вместо `user_id` для общих). Исполнение считается по операциям всех счетов группы с видимостью `full` и категориями из поддерева. Категории общих бюджетов — системные (у пользовательских разные id). Альтернатива — групповые категории (**решить** по итогам исследования с пользователями).
- **Общие цели:** `savings_goals.group_id`; взносы `goal_contributions.user_id` показывают вклад каждого.
- **Права на сервере:** единый слой `access.ts`. Функция `canRead(userId, resource)` проверяет владельца или общий доступ через группу. Все запросы E1.* по счетам и операциям получают режим `scope=me|family`. Обязательные тесты на утечки: участник без `full` не видит операции, бывший участник не видит ничего.
- **Синхронизация:** `/v1/sync` (E2.1) отдаёт общие сущности с полем `ownerUserId`.
- **Тариф:** функции группы доступны, пока у владельца активен тариф «Семья». При окончании тарифа группа становится доступна только для чтения на 30 дней.

## Модель данных крупно
```ts
// family_groups: + plan_owner_user_id, max_members int default 6, updated_at; invite_code удалить
// family_group_members: role → owner|adult|teen; + left_at; UQ(user_id) where left_at is null
familyInvites(id, groupId, tokenHash, role, createdBy, expiresAt, acceptedBy, acceptedAt)
accountShares(accountId PK → accounts, groupId, visibility, updatedAt)
// budgets: + group_id (nullable, XOR с user_id для владельца — оставить user_id = создатель, group_id = общий)
// savings_goals: + group_id
// goal_contributions: user_id уже есть
```

## API крупно
- `POST /v1/family` (создать группу), `GET /v1/family`, `PATCH /v1/family`.
- `POST /v1/family/invites`, `POST /v1/family/invites/{token}/accept`.
- `DELETE /v1/family/members/{userId}` (исключить), `POST /v1/family/leave`.
- `PUT /v1/accounts/{id}/share` `{ visibility }`.
- Существующие `GET /v1/transactions`, `/v1/budgets`, `/v1/goals`, `/v1/dashboard/summary` получают `?scope=family`.

## Экраны
- **«Семья»:** участники и роли, приглашение (ссылка, QR), общие бюджеты и цели, «Чем я делюсь» (список своих счетов с переключателем видимости).
- **Главная в режиме «Семья»:** переключатель «Я / Семья» в шапке.
- **Пусто:** «Ведите бюджет вместе» с объяснением приватности.

## Метрика
≥ 8% платящих — на тарифе «Семья». У групп среднее число участников ≥ 2,3. D30 участников групп выше среднего.

## Риски и вопросы
- **Приватность** — главный риск: утечка операций между участниками недопустима. Отдельный ревью-чеклист прав и e2e-тесты.
- **Персональные данные** других людей в группе: согласие участника при вступлении; выход немедленно убирает доступ.
- **Вопрос:** нужны ли общие счета без владельца (наличные «на хозяйство»)? Предлагается заводить такой счёт у владельца с видимостью `full`.
