# E2.9 — Публикация Android: RuStore, Google Play, APK

**Оценка:** 6 дней (без ожидания модерации) · **Зависит от:** E2.1, E2.3 (разрешения), E2.8 (оплата в варианте `rustore`), D13, D14 · **Блокирует:** публичный запуск этапа 2

## Цель
Выпустить Android-приложение в каналы, где его найдут российские пользователи:
- **RuStore** — основной канал: предустановка, 68 млн MAU, оплата RuStore Pay;
- **Google Play** — бесплатная версия без оплаты;
- **APK с fin-wall.ru** — для тех, у кого нет ни одного стора.

Пройти модерацию с первого раза.

## Ключевые решения
- **Варианты сборки** (из E2.1):

| Вариант | Канал | Оплата | Уведомления банков | SMS | Обновления |
|---|---|---|---|---|---|
| `rustore` | RuStore | RuStore Pay + веб | да | да (**проверить** политику RuStore) | RuStore In-App Updates SDK (**проверить**) |
| `play` | Google Play | нет UI оплаты | да, с декларацией (D14) | нет | Play In-App Updates |
| `apk` | fin-wall.ru/app | веб | да | да | проверка версии через `GET /v1/app/version` и загрузка нового APK |

- **Подпись:** отдельный upload-ключ для Google Play (Play App Signing) и собственный ключ для RuStore и APK. Хранение ключей — секреты GitHub Actions плюс офлайн-копия у владельца. Через EAS — только при решении D13 в его пользу.
- **Аккаунты разработчика:**
  - RuStore — регистрация юрлица, ИП, самозанятого или физлица (**проверить** требования для монетизации — нужен юрлицо или ИП, D3);
  - Google Play — регистрационный взнос $25 (оплата из РФ затруднена, **проверить** способы), верификация личности или организации, для новых личных аккаунтов — закрытое тестирование с ≥ 12 тестировщиками в течение 14 дней перед продом (**проверить** актуальные правила).
- **Требования Google Play** (**проверить** актуальные на дату подачи):
  - target API level (с августа 2025 — API 35 для новых приложений; к августу 2026 ожидается API 36);
  - форма Data safety;
  - декларация Financial features (приложение для управления личными финансами, без кредитования);
  - декларация доступа к уведомлениям с видео-демонстрацией раскрытия;
  - ссылка на удаление аккаунта (веб-страница `fin-wall.ru/account/delete` с удалением по 152-ФЗ);
  - политика конфиденциальности.
- **Обязательные документы на сайте:**
  - политика конфиденциальности (обработка ПДн по 152-ФЗ, перечень обработчиков, трансграничная передача — по D2);
  - пользовательское соглашение;
  - оферта подписки (E2.8);
  - согласие на обработку ПДн с версионированием (этап 0 / 152-ФЗ).
- **Материалы стора:**
  - иконка 512, фичер-графика;
  - 4–8 скриншотов на русском, **без логотипов и названий банков** (товарные знаки, iOS-ревью);
  - короткое и полное описание;
  - категория «Финансы»;
  - возрастной рейтинг.
- **Мониторинг после релиза:** ANR/crash (Play Console, RuStore Console, GlitchTip/Sentry), ответы на отзывы в консолях сторов в течение 2 рабочих дней.

## Модель данных и API крупно
- `GET /v1/app/version?platform=android&flavor=apk` → `{ latest, minSupported, url, sha256, changelog }` — без авторизации.
- При `minSupported` выше версии клиента приложение показывает экран «Обновите приложение».
- Таблица не нужна: значения в `system_settings` (уже есть) с ключами `app.android.*`.

## Экраны
Экран «Обновите приложение» (принудительное и мягкое обновление). Страницы на сайте: `/app` (скачать APK с SHA-256 и инструкцией «разрешить установку из неизвестных источников»), `/privacy`, `/terms`, `/account/delete`.

## Метрика
Публикация в RuStore и Google Play. Рейтинг ≥ 4,3 через 3 месяца. Crash-free ≥ 99,5%. Конверсия страницы стора в установку — отслеживать по каналам.

## Риски и вопросы
- **Отказ Google Play** из-за доступа к уведомлениям: выпустить `play` без функции, оставить её в `rustore` и `apk` (D14).
- **Блокировка аккаунта Google Play** по санкционным основаниям: RuStore и APK — основные каналы, PWA — страховка.
- **Юрлицо для RuStore Pay** (D3).
