# Banks Router (`/api/banks/*`)

Комплексный модуль управления банковскими подключениями, платежами, счетами и транзакциями.

## Основные функции
- Подключение к банкам через ПКС (Платежная Карточная Система)
- Управление российскими платежными системами
- Работа со счетами и транзакциями
- OAuth2 интеграция с банками

## Банковские подключения

### GET `/api/banks/connections`
**Получить подключения пользователя**
- Список активных банковских подключений
- Статус каждого подключения
- Время последней синхронизации

### POST `/api/banks/connect`
**Инициировать подключение к банку**
- Запуск OAuth2 процесса
- Генерация consent ID
- Редирект на банковскую авторизацию

### POST `/api/banks/oauth-callback`
**Обработка OAuth callback**
- Получение authorization code
- Обмен на access token
- Сохранение подключения

### DELETE `/api/banks/connections/:connectionId`
**Отключить банк**
- Отзыв токенов доступа
- Удаление подключения
- Очистка связанных данных

### GET `/api/banks/available`
**Доступные банки для подключения**
- Сбербанк, ВТБ, Тинькофф, Альфа-Банк
- Газпромбанк, Райффайзенбанк
- Описания и возможности каждого банка

## ПКС интеграция (Real Bank API)

### GET `/api/banks/real/available`
**Банки с ПКС поддержкой**
- Список банков с Open Banking API
- Технические характеристики
- Поддерживаемые операции

### POST `/api/banks/real/connect`
**Подключение через ПКС**
- Инициация реального банковского подключения
- Соответствие стандартам ЦБ РФ
- Безопасная авторизация

### GET `/api/banks/real/callback/:bankCode`
**ПКС OAuth callback**
- Обработка реального банковского ответа
- Валидация state параметра
- Сохранение производственных токенов

### POST `/api/banks/real/sync/:connectionId`
**Синхронизация данных банка**
- Загрузка актуальных остатков
- Получение новых транзакций
- Обновление курсов валют

## Платежные системы

### GET `/api/banks/payments/providers`
**Российские платежные провайдеры**
- ЮKassa (Яндекс.Касса)
- CloudPayments  
- Сбербанк Эквайринг
- Возможности каждого провайдера

### POST `/api/banks/payments/create`
**Создать платеж**
- Формирование платежного поручения
- Генерация уникального order ID
- Интеграция с выбранным провайдером
- Возврат ссылки для оплаты

### POST `/api/banks/payments/subscription`
**Создать подписку**
- Рекуррентные платежи
- Управление подписками
- Автоматическое списание

### GET `/api/banks/payments/status/:paymentId`
**Статус платежа**
- Отслеживание статуса оплаты
- Уведомления об изменениях
- История операций

## Счета и транзакции

### GET `/api/banks/accounts`
**Получить счета пользователя**
- Все банковские счета
- Актуальные остатки
- Типы счетов (расчетный, сберегательный, карточный)

### GET `/api/banks/transactions`
**Получить транзакции**
- История операций
- Фильтрация по периоду
- Поддержка пагинации (limit параметр)
- Категоризация операций

## Поддерживаемые банки

### Tier 1 (Полная интеграция)
- **Сбербанк** - крупнейший банк России
- **ВТБ** - второй по величине банк
- **Тинькофф** - лидер цифрового банкинга

### Tier 2 (Базовая интеграция)  
- **Альфа-Банк** - крупнейший частный банк
- **Газпромбанк** - банк с государственным участием
- **Райффайзенбанк** - европейский банк в России

## Безопасность

### OAuth2 процесс
- Стандартные authorization code flow
- State параметр для защиты от CSRF
- Secure хранение токенов
- Автоматическое обновление access токенов

### Шифрование данных
- Токены доступа зашифрованы в БД
- PCI DSS compliance для платежных данных
- Логирование всех операций

## Российское законодательство

### ФЗ-161 "О банках"
- Соответствие требованиям ЦБ РФ
- Лицензированные операции
- Соблюдение валютного законодательства

### 152-ФЗ "О персональных данных"
- Защита финансовых данных
- Согласие на обработку
- Право на удаление данных

## Используемые сервисы
- `bankService` - управление подключениями
- `bankApiService` - ПКС интеграция  
- `paymentService` - российские платежи
- `storage` - сохранение данных
