# Admin Router (`/api/admin/*`)

Модуль административного управления FinTrack с многоуровневой системой прав.

## Система ролей
- **Super Admin** - полный доступ ко всем функциям
- **DevOps Admin** - управление инфраструктурой и мониторинг
- **Analytics Admin** - доступ к аналитике и отчетам
- **Finance Admin** - управление финансовыми операциями
- **API Admin** - управление API ключами и интеграциями
- **Security Admin** - управление безопасностью и документами

## Роуты

### Управление пользователями

#### GET `/api/admin/users`
**Получить список всех пользователей**
- Права: `user.read`
- Возвращает полную информацию о пользователях
- Поддержка пагинации и фильтрации

#### PUT `/api/admin/users/:userId/role`
**Изменить роль пользователя**
- Права: `user.manage`
- Обновление основной роли и админских привилегий
- Логирование изменений

#### DELETE `/api/admin/users/:userId`
**Удалить пользователя**
- Права: `user.manage`
- Каскадное удаление связанных данных
- Аудит операции

### Управление документами

#### GET `/api/admin/documents/pending`
**Документы на модерации**
- Права: `documents.moderate`
- Список документов со статусом "pending"
- Группировка по пользователям

#### PUT `/api/admin/documents/:documentId/status`
**Изменить статус документа**
- Права: `documents.moderate`
- Статусы: pending → verified/rejected
- Автоматическое обновление уровня верификации пользователя

#### GET `/api/admin/documents/stats`
**Статистика по документам**
- Права: `documents.read`
- Количество по статусам
- Распределение по типам

### Система логирования

#### GET `/api/admin/logs`
**Получить логи административных действий**
- Права: `logs.read`
- Фильтрация по пользователю, действию, дате
- Поддержка пагинации

### Системная информация

#### GET `/api/admin/stats`
**Общая статистика системы**
- Права: `analytics.read`
- Количество пользователей, документов, транзакций
- Метрики производительности

## Middleware и безопасность

### `requireAdmin`
Проверяет наличие административной роли у пользователя.

### `requirePermission(permission)`
Проверяет конкретное разрешение:
- `user.read`, `user.manage` - управление пользователями
- `documents.read`, `documents.moderate` - работа с документами
- `analytics.read` - доступ к аналитике
- `logs.read` - просмотр логов
- `dashboard.analytics` - админская панель

## Аудит и логирование
Все административные действия автоматически логируются:
- Кто выполнил действие (userId, adminRole)
- Что было сделано (action, resourceType)
- Когда (timestamp)
- Дополнительные данные (metadata)

## Используемые сервисы
- `storage` - работа с базой данных
- `adminLogService` - логирование действий
- `documentVerificationService` - обновление статусов верификации
