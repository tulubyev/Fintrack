# Verification Router (`/api/verification/*`)

Модуль верификации пользователей через SMS и Email.

## Основные функции
- Отправка SMS кодов подтверждения
- Отправка Email кодов подтверждения
- Верификация введенных кодов
- Тестирование SMS и Email сервисов

## Роуты

### SMS Верификация

#### POST `/api/verification/send-sms`
**Отправить SMS код**
- Требует авторизации
- Генерация 6-значного кода
- Отправка через SMS.RU API
- Валидация номера телефона

**Запрос:**
```json
{
  "phone": "+79991234567"
}
```

**Ответ:**
```json
{
  "success": true,
  "message": "SMS код отправлен",
  "expiredAt": "2025-09-08T10:15:00Z"
}
```

#### POST `/api/verification/verify-sms`
**Проверить SMS код**
- Валидация 6-значного кода
- Проверка времени действия (5 минут)
- Обновление статуса верификации пользователя

**Запрос:**
```json
{
  "phone": "+79991234567",
  "code": "123456"
}
```

### Email Верификация

#### POST `/api/verification/send-email`
**Отправить Email код**
- Генерация 6-значного кода
- Отправка через SMTP (Beget)
- HTML шаблон письма
- Валидация email адреса

**Запрос:**
```json
{
  "email": "user@example.com"
}
```

#### POST `/api/verification/verify-email`
**Проверить Email код**
- Валидация кода
- Обновление статуса email верификации
- Проверка времени действия

**Запрос:**
```json
{
  "email": "user@example.com",
  "code": "123456"
}
```

### Тестирование сервисов

#### GET `/api/verification/test-sms`
**Протестировать SMS сервис**
- Проверка подключения к SMS.RU
- Проверка баланса
- Статус API ключа

**Ответ:**
```json
{
  "success": true,
  "balance": 1010,
  "provider": "SMS.RU"
}
```

#### GET `/api/verification/test-email`
**Протестировать Email сервис**
- Проверка SMTP подключения
- Валидация конфигурации
- Статус сервиса

## Безопасность

### Защита от злоупотреблений
- Rate limiting: не более 3 SMS в час на номер
- Rate limiting: не более 5 Email в час на адрес
- Проверка валидности номеров/email
- Логирование всех попыток

### Коды подтверждения
- **Длина**: 6 цифр
- **Время жизни**: 5 минут
- **Одноразовые**: код удаляется после использования
- **Криптографически стойкие**: генерация через crypto.randomInt()

## Провайдеры

### SMS
- **SMS.RU** - основной провайдер
- API ключ из переменной `SMS_RU_API_KEY`
- Поддержка международных номеров
- Мониторинг баланса

### Email
- **SMTP Beget** - основной провайдер
- Конфигурация через переменные:
  - `BEGET_SMTP_HOST`
  - `BEGET_SMTP_PORT`
  - `BEGET_SMTP_USER`
  - `BEGET_SMTP_PASSWORD`

## Используемые сервисы
- `verificationService` - основная логика верификации
- SMS.RU API - отправка SMS
- Nodemailer + SMTP - отправка Email
- `storage` - сохранение кодов и статусов

## Статусы верификации
- `isPhoneVerified` - подтвержден номер телефона
- `isEmailVerified` - подтвержден email адрес
- Обновляются автоматически при успешной верификации
