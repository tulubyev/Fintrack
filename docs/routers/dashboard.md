# Dashboard Router (`/api/dashboard/*`)

Модуль аналитики и статистики для главной панели FinTrack.

## Основные функции
- Сводная финансовая статистика пользователя
- Анализ трат по категориям
- Данные для построения графиков и диаграмм
- Административная аналитика (планируется)

## Роуты

### GET `/api/dashboard/stats`
**Основная финансовая статистика**

Возвращает ключевые финансовые показатели пользователя за текущий месяц.

**Данные:**
- `totalBalance` - общий баланс всех счетов
- `monthlyIncome` - доходы за текущий месяц  
- `monthlyExpenses` - расходы за текущий месяц
- `totalSavings` - общая сумма накоплений
- `savingsGoalsCount` - количество целей накопления

**Ответ:**
```json
{
  "totalBalance": 150000.50,
  "monthlyIncome": 85000.00,
  "monthlyExpenses": 32500.75,
  "totalSavings": 45000.00,
  "savingsGoalsCount": 3
}
```

**Использование:**
- Главные карточки на дашборде
- Кольцевые диаграммы доходов/расходов
- Прогресс-бары накоплений

### GET `/api/dashboard/spending-categories`
**Анализ трат по категориям**

Распределение месячных расходов по категориям для построения аналитики.

**Возможные категории:**
- Продукты питания
- Транспорт
- Развлечения
- Коммунальные услуги
- Одежда и обувь
- Медицина
- Образование
- Прочее

**Ответ:**
```json
[
  {
    "category": "Продукты питания",
    "amount": 15000.00,
    "percentage": 46.2
  },
  {
    "category": "Транспорт", 
    "amount": 8500.00,
    "percentage": 26.1
  },
  {
    "category": "Развлечения",
    "amount": 5200.00,
    "percentage": 16.0
  }
]
```

**Использование:**
- Круговые диаграммы трат
- Горизонтальные бар-чарты
- Рекомендации по оптимизации бюджета

### `/api/dashboard/admin/metrics` (планируется)
**Административная аналитика**

*Временно отключен* - планируется для супер-администраторов.

**Планируемые метрики:**
- Общее количество пользователей в системе
- Количество активных подключений к банкам
- Объем обработанных транзакций
- Статистика верификации документов
- Нагрузка на систему

## Технические особенности

### Производительность
- **Параллельные запросы**: Использует `Promise.all()` для одновременного получения данных
- **Кэширование**: Данные актуализируются в реальном времени
- **Оптимизация БД**: Индексированные запросы по userId и датам

### Период расчета
- **Автоматический**: Использует текущий месяц и год
- **Динамический**: Обновляется автоматически при смене месяца
- **Часовой пояс**: Расчет по серверному времени

### Безопасность
- **Авторизация**: Все роуты требуют валидный JWT токен
- **Изоляция данных**: Пользователи видят только свои данные
- **Валидация**: Проверка прав доступа на каждый запрос

## Интеграция с фронтендом

### Компоненты дашборда
- `StatsCards` - карточки с основными показателями
- `SpendingChart` - круговая диаграмма трат  
- `IncomeExpenseChart` - сравнение доходов и расходов
- `SavingsProgress` - прогресс целей накопления

### Библиотеки для графиков
- Recharts - для React диаграмм
- Chart.js - альтернативная библиотека
- D3.js - для сложной визуализации
