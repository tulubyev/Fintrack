# Documents Router (`/api/documents/*`)

Модуль управления документами с шифрованием и верификацией.

## Основные функции
- Загрузка и хранение документов пользователей
- End-to-End шифрование файлов
- Управление типами документов
- Безопасный просмотр и скачивание

## Роуты

### GET `/api/documents/types`
**Получить типы документов**
- Список доступных типов для загрузки
- Паспорт, водительские права, СНИЛС, ИНН и др.
- С русскими названиями (displayName)

### GET `/api/documents`
**Получить документы пользователя**
- Список загруженных документов
- Информация о статусе верификации
- Метаданные без содержимого файлов

### POST `/api/documents/upload`
**Загрузить документ**
- Мультипарт загрузка файла
- AES-256 шифрование
- Генерация checksum для проверки целостности
- Сохранение метаданных в БД

### GET `/api/documents/:documentId/download`
**Скачать документ**
- Доступ только владельцу или админу
- Автоматическая расшифровка
- Проверка целостности файла
- Content-Disposition: attachment

### GET `/api/documents/:documentId/view`
**Просмотр документа в браузере**
- Поддержка токена в query параметрах
- Content-Disposition: inline
- Безопасные заголовки (X-Frame-Options, X-Content-Type-Options)
- Доступ для модерации администраторами

### DELETE `/api/documents/:documentId`
**Удалить документ**
- Только владелец может удалять
- Физическое удаление зашифрованного файла
- Удаление записи из БД

## Безопасность

### Шифрование
- **Алгоритм**: AES-256-GCM
- **Ключи**: Уникальные для каждого пользователя
- **IV**: Случайный для каждого файла
- **Хранение**: Зашифрованные файлы + метаданные отдельно

### Права доступа
- **Пользователи**: только свои документы
- **Администраторы**: super_admin и security_admin могут просматривать все документы
- **Расшифровка**: используется ключ владельца документа

### Проверка целостности
- SHA-256 checksum для каждого файла
- Автоматическая верификация при доступе
- Обнаружение повреждений

## Типы документов

### Основные
- `passport` - Паспорт РФ
- `foreign_passport` - Загранпаспорт
- `driver_license` - Водительское удостоверение
- `snils` - СНИЛС
- `inn` - ИНН

### Дополнительные
- `income` - Справки о доходах
- `bank_statement` - Банковские выписки
- `property` - Документы на недвижимость

## Хранение файлов
```
server/storage/documents/
├── {userId}/
│   ├── doc_abc123_timestamp_uuid.jpg.enc
│   └── doc_def456_timestamp_uuid.pdf.enc
```

## Используемые сервисы
- `documentStorageService` - шифрование и хранение файлов
- `storage` - работа с метаданными в БД
- `multer` - обработка мультипарт форм
- `sharp` - обработка изображений (при необходимости)

## Ограничения
- Максимальный размер файла: 10 MB
- Поддерживаемые форматы: JPG, PNG, PDF, DOC, DOCX
- Максимальное количество документов одного типа: 3
