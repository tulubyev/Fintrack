# Система верификации пользователей FinTrack

## 📋 Общие положения

### Цели и задачи
Система верификации FinTrack обеспечивает соответствие требованиям российского законодательства при соблюдении этических принципов и защиты персональных данных пользователей.

### Принципы верификации
- **Минимальная достаточность** - сбор только необходимых данных
- **Прозрачность** - понятные требования для пользователей  
- **Безопасность** - защита персональных данных
- **Соответствие законодательству** - выполнение требований 115-ФЗ и ЦБ РФ
- **Отказ от биометрии** - по этическим соображениям

## 🎯 Нормативная база

### Федеральное законодательство
- **115-ФЗ** "О противодействии легализации доходов..."
- **149-ФЗ** "Об информации, информационных технологиях..."
- **152-ФЗ** "О персональных данных"
- **ГОСТ Р 57580.1-2017** "Финансовые услуги. Онлайн-идентификация"

- Положение 550-П о требованиях к НФО
- Указание 4482-У об идентификации клиентов
- Требования к упрощенной идентификации

## 🏗️ Уровни верификации

### Уровень 1: Упрощенная идентификация
**Лимиты операций:**
- Максимальная сумма операций: 15 000 ₽/месяц
- Максимальный остаток: 15 000 ₽

**Требования:**
- ✅ Подтверждение номера телефона (SMS)
- ✅ Указание ФИО, даты рождения
- ✅ Подтверждение email-адреса
- ✅ Согласие на обработку персональных данных

**Процесс верификации:**
1. Регистрация с указанием основных данных
2. Отправка SMS-кода на указанный номер
3. Подтверждение email через письмо со ссылкой
4. Автоматическое присвоение Уровня 1

### Уровень 2: Стандартная идентификация
**Лимиты операций:**
- Максимальная сумма операций: 100 000 ₽/месяц  
- Максимальный остаток: 60 000 ₽

**Требования:**
- ✅ Все требования Уровня 1
- ✅ Загрузка документа, удостоверяющего личность
- ✅ Автоматическая проверка документа
- ✅ Указание адреса регистрации
- ✅ Подтверждение места работы (необязательно)

**Процесс верификации:**
1. Выполнение всех требований Уровня 1
2. Загрузка скана/фото паспорта (разворот с фото)
3. Автоматическая проверка документа через OCR
4. Модерация спорных случаев оператором
5. Присвоение Уровня 2 при успешной проверке

### Уровень 3: Полная идентификация
**Лимиты операций:**
- Максимальная сумма операций: 600 000 ₽/месяц
- Максимальный остаток: без ограничений

**Требования:**
- ✅ Все требования Уровня 2
- ✅ Интеграция с Госуслугами (ESIA)
- ✅ Банковская верификация переводом
- ✅ Видеозвонок с оператором (при необходимости)
- ✅ Дополнительные документы по запросу

**Процесс верификации:**
1. Выполнение всех требований Уровня 2
2. Авторизация через Госуслуги с подтвержденной учетной записью
3. Верификация банковским переводом (1-10 ₽)
4. При необходимости - видеозвонок с оператором
5. Присвоение Уровня 3

## 📱 Методы верификации

### 1. SMS-верификация телефона

**Технические требования:**
- Поддержка российских и международных номеров
- 6-значный цифровой код
- Время действия кода: 5 минут
- Ограничения: максимум 3 попытки в час

**Провайдеры SMS:**
- **Основной**: SMSC.ru (российский провайдер)
- **Резервный**: SMS.ru (высокая доставляемость)
- **Корпоративный**: StreamTelecom (для больших объемов)

**Безопасность:**
- Логирование всех SMS для аудита
- Защита от флуда и спама
- Блокировка подозрительных номеров

### 2. Верификация документов

**Принимаемые документы:**
- Паспорт РФ (основной разворот с фото)
- Загранпаспорт РФ
- Водительское удостоверение РФ
- Военный билет

**Технология обработки:**
- **Smart Engines** - распознавание российских документов
- **ABBYY FlexiCapture** - OCR и извлечение данных
- Автоматическая проверка на подлинность

**Проверяемые параметры:**
- Читаемость документа
- Соответствие формату российских документов
- Извлечение и валидация данных (ФИО, номер, дата выдачи)
- Проверка контрольных сумм
- Сверка с базами недействительных документов

### 3. Интеграция с Госуслугами (ESIA)

**Возможности интеграции:**
- OAuth 2.0 авторизация
- Получение подтвержденных персональных данных
- Автоматическое присвоение высокого уровня доверия
- Проверка статуса учетной записи

**Получаемые данные:**
- ФИО (подтвержденные)
- Дата рождения
- СНИЛС
- ИНН (при наличии)
- Статус верификации в ЕСИА

### 4. Банковская верификация

**Механизм работы:**
1. Пользователь инициирует банковскую верификацию
2. Система генерирует уникальный код верификации
3. Пользователь переводит символическую сумму (1-10 ₽) 
4. В назначении платежа указывает код верификации
5. Система получает выписку через банковское API
6. Автоматическое подтверждение владения банковским счетом

**Партнеры для интеграции:**
- **СБП (Система быстрых платежей)** - универсальное решение
- **Сбербанк** - корпоративное API
- **ВТБ** - Open Banking API
- **Тинькофф** - Tinkoff Acquiring API

### 5. Видеозвонок с оператором

**Применение:**
- Спорные случаи верификации документов
- Дополнительная проверка для Уровня 3
- Разрешение конфликтных ситуаций
- VIP-клиенты по запросу

**Процедура:**
1. Назначение видеозвонка через систему
2. Проверка документов в режиме реального времени
3. Устное подтверждение персональных данных
4. Протоколирование результатов звонка
5. Принятие окончательного решения
