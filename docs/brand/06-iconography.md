# 6. Иконки, иллюстрации, форма

## Набор иконок: Lucide на обеих платформах

Сейчас: веб — `lucide-react` (51 файл), приложение — Ionicons из `@expo/vector-icons`. Одна и та же функция выглядит по-разному:
у Lucide линия 2 px и прямые концы, у Ionicons — смесь контурных и залитых форм с другой геометрией.

**Рекомендация — выровнять на Lucide**, но не срочно (шаг 6 плана в README):

| | Lucide | Ionicons (оставить) |
|---|---|---|
| Лицензия | ISC — свободная | MIT — свободная |
| Веб | уже везде | — |
| Приложение | `lucide-react-native` (1.61.0) + `react-native-svg` — работает в Expo Go и в сборках, iOS и Android | уже подключено |
| Единый вид веба и приложения | да, те же имена: `ArrowLeftRight`, `PieChart`, `Wallet` | нет |
| Стоимость | 1–2 дня: обёртка `Icon` в `kit.tsx` + таблица соответствия имён (~60 имён) | 0 |

Переход делается внутри `Icon` в `kit.tsx`: экраны передают имя, обёртка рисует Lucide. Тип `IconName` меняется на
объединение используемых имён — компилятор покажет все места.

## Правила иконок

| Параметр | Значение |
|---|---|
| Стиль | контурные, без заливок; залитая — только активная вкладка, если нужна разница |
| Толщина линии | **1,75** при 20–24 px (у Lucide по умолчанию 2 — чуть тяжелее Onest Regular) |
| Размеры | 16 (в тексте, бейджах), 20 (кнопки, списки), 24 (навигация), 40 (пустое состояние) |
| Цвет | `foreground` или `muted-foreground`; `primary` — активное; цвет смысла (`income`, `warning`, `destructive`) — только с этим смыслом |
| Подложка в списке | квадрат 32–36 px, скругление 10, фон `subtle` — как `listIcon` в `kit.tsx` |
| Направление денег | `arrow-down-left` — доход, `arrow-up-right` — расход, `arrow-left-right` — перевод между своими |
| Советник | `sparkles` в цвете `brand-accent` — только у советов |

## Иллюстрации для пустых состояний

Пример — в `brand-preview.html` (карточка «Здесь появятся ваши траты»).

- **Геометрия из знака.** Плашки-«кирпичи» со скруглением 3,5, документы, стрелки. Никаких персонажей, 3D, градиентов и фотостока:
  спокойствие и честность не вяжутся с мультяшным маскотом.
- **Линия 1,75** — как у иконок, концы скруглены.
- **Два цвета + нейтральный**: контур `muted-foreground`, акцент `primary`, заливки — `card` и `chart-1` с прозрачностью 55%.
  Цвета задаются CSS-переменными (`var(--primary)`), поэтому одна SVG работает в обеих темах.
- **Размер** 120–160 × 80–112 px, над заголовком пустого состояния. В приложении — тот же SVG через `react-native-svg` с цветами из `useColors()`.
- **Сюжет показывает действие, которое решит пустоту**: выписка → кладка (импорт), плашка с плюсом (первая операция),
  кирпич с отметкой лимита (бюджет), кирпичи с повтором (подписки).

## Форма

| | Значение | Где |
|---|---|---|
| Скругление 4 | `xs` | бейджи-квадраты, мелкие метки |
| Скругление 8 | `sm` | чипы-квадраты, иконки 32 px |
| Скругление 12 | `md` = `--radius` на вебе | кнопки, поля ввода, плашки уведомлений |
| Скругление 16 | `lg` | карточки, группы списков (`Section`) |
| Скругление 24 | `xl` | нижние листы, большие карточки на лендинге |
| Пилюля | `pill` | чипы фильтров, бейджи статуса |

Сейчас на вебе `--radius: 0.75rem` (12 px) и в приложении `radius.md = 12` — совпадает с предложением, менять не нужно.

## Тени и глубина

- Карточки отделяются **границей 1 px** (`border`), без тени — так спокойнее и одинаково в обеих темах.
- Тень `shadow-raised` (0 1px 2px, 6%) — допустима у карточек на лендинге.
- Тень `shadow-overlay` — меню, поповеры, диалоги.
- Тень `shadow-fab` — только у круглой кнопки «+».
- В тёмной теме тени почти не видны — глубину дают оттенки: фон `#0E1314` → карточка `#161D1E` → подложка `#1E2729`.

## Плотность

- Цель касания — **не меньше 48 × 48 dp** (кнопки уже `minHeight: 48`).
- Строка операции — 56 dp (две строки текста), строка настроек — 52 dp (как `listItem` в `kit.tsx`).
- Отступы — шаг 4: 4 / 8 / 12 / 16 / 24 / 32 / 48. Поля экрана — 16, между карточками — 12–16.
- **Одна главная цифра на экран.** Остальные суммы — `amount` 16 px. Не больше одного акцентного блока советника на экране.

## Движение

- 120 мс — нажатия и переключатели, 200 мс — появление листов и меню, 320 мс — переходы экранов.
- Кривая `cubic-bezier(0.2, 0, 0, 1)`.
- При `prefers-reduced-motion` (и «Удалить анимации» в Android) — без сдвигов и конфетти у целей, только смена прозрачности.
