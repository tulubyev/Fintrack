## 🎯 План пошагового рефакторинга

### Этап 1: Frontend модулизация (приоритет)
1. **Вынести модальные окна из App.tsx в отдельные файлы** 
   - ApiKeysModal.tsx, SyncModal.tsx, WebhooksModal.tsx, SecurityModal.tsx
   
2. **Создать компоненты админ-панели**
   - AdminPanel.tsx (главный компонент)
   - UserManagement.tsx, DocumentModeration.tsx, SystemMonitoring.tsx, ApiManagement.tsx

3. **Создать контексты для управления состоянием**
   - AuthContext.tsx, AdminContext.tsx

4. **Создать кастомные хуки**
   - useAdmin.ts, useDashboard.ts

### Этап 2: Backend модулизация
1. **Разделить routes.ts на специализированные роутеры**
2. **Создать middleware для общей логики**
3. **Оптимизировать storage.ts**

### Этап 3: Очистка и оптимизация
1. **Удалить дублирующие файлы** (App_broken.tsx, App-broken.tsx)
2. **Провести code review всех модулей**
3. **Обновить документацию**
