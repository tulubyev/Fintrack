# 🛡️ FinTrack Backup & Restore System

Комплексная система резервного копирования и восстановления для FinTrack MVP.

## 🎯 Возможности

### Backup System (`backup.ts`)
- **База данных PostgreSQL** - полный дамп с pg_dump + альтернативный режим
- **Файлы приложения** - весь код (server, client, shared, конфиги)
- **Загруженные документы** - пользовательские файлы из папки uploads
- **Метаданные** - информация о версии, времени создания, инструкции
- **Архивирование** - сжатие в .tar.gz с SHA256 проверкой целостности

### Restore System (`restore.ts`)
- **Проверка целостности** - верификация SHA256 хэша архива
- **Поэтапное восстановление** - база данных, файлы, загрузки
- **Безопасность** - резервные копии текущих файлов перед заменой
- **Инструкции** - автоматические подсказки по завершению

## 🚀 Использование

### Создание Backup

```bash
# Полный backup (рекомендуется)
npm run backup

# Или через tsx напрямую
tsx scripts/backup.ts
```

### Восстановление из Backup

```bash
# Восстановление из архива
npm run restore ./backups/backup-2025-01-15T10-30-00.tar.gz

# Или через tsx напрямую
tsx scripts/restore.ts ./backups/backup-2025-01-15T10-30-00.tar.gz
```

## 📋 Структура Backup

```
backup-2025-01-15T10-30-00/
├── backup_metadata.json     # Метаданные и инструкции
├── database.sql            # Дамп PostgreSQL базы

│   ├── shared/            # Общие типы/схемы

```

## ⚙️ Требования

### Для создания Backup
- PostgreSQL клиент (pg_dump) - желательно
- Node.js с tsx
- Доступ к DATABASE_URL

### Для восстановления
- PostgreSQL клиент (psql) - для восстановления БД
- Права записи в текущую директорию
- DATABASE_URL для автоматического восстановления БД

## 🔧 Конфигурация

### Package.json Scripts

Добавьте в `package.json`:

```json
{
  "scripts": {
    "backup": "tsx scripts/backup.ts",
    "restore": "tsx scripts/restore.ts"
  }
}
```

### Автоматические Backup

Для регулярных backup можно настроить cron или GitHub Actions:

```bash
# Ежедневный backup в 3:00
0 3 * * * cd /path/to/fintrack && npm run backup
```

## 🛡️ Безопасность

### Что НЕ включается в Backup
- ❌ **Секреты и API ключи** - переменные окружения не сохраняются
- ❌ **node_modules** - зависимости восстанавливаются через npm install
- ❌ **Логи и временные файлы** - только важные данные
- ❌ **Git история** - .git папка исключается

### Рекомендации
- 🔐 Храните backup в безопасном месте
- 🔄 Регулярно проверяйте возможность восстановления
- 📝 Документируйте пароли и секреты отдельно
- 🎯 Тестируйте backup/restore в изолированной среде

## 🚨 Аварийное восстановление

### Если автоматическое восстановление не работает:

1. **База данных вручную:**
```bash
# Распакуйте архив
tar -xzf backup-*.tar.gz

# Восстановите БД
psql -d your_database < restored/database.sql
```

2. **Файлы вручную:**
```bash
# Скопируйте файлы приложения
cp -r restored/app/* ./
npm install
```

3. **Загрузки вручную:**
```bash
# Восстановите пользовательские файлы
cp -r restored/uploads ./
```
