# FinTrack

вход через Госуслуги (ЕСИА). Прод: https://fin-wall.ru

- Правила работы и архитектурные решения — [CLAUDE.md](CLAUDE.md)
- Развёртывание на VPS, обновление, откат, бэкапы — [docs/DEPLOY.md](docs/DEPLOY.md)
- Переменные окружения — [.env.example](.env.example)

```bash
pnpm install
pnpm run build   # typecheck + сборка
```
